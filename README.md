# Ultimate Brick Breaker – 대결(멀티플레이) 서버

## 1. 실행 방법 (내 컴퓨터를 서버로 쓰기)
1. Node.js 16 이상 설치 (https://nodejs.org)
2. 이 폴더에서 터미널을 열고:
   ```
   npm install
   npm start
   ```
3. 터미널에 나온 주소로 접속합니다.
   - 내 컴퓨터: `http://localhost:3000`
   - 같은 와이파이의 친구: `http://(터미널에 표시된 IP):3000`

> 게임 화면(index.html)도 이 서버가 함께 내려주므로, **친구도 같은 주소로 접속**하면 서버 주소 설정이 자동으로 맞춰집니다.

## 2. 대결하는 방법
1. 상단의 **⚔️ 대결하기** 버튼 → 이름과 **팀 코드**(영문/숫자 3~12자) 입력 → 입장
2. 친구도 **같은 팀 코드**를 입력하면 같은 방에 들어옵니다 (최대 4명, 대소문자 무관)
3. 방장(👑)이 **대결 시작**을 누르면 모두 같은 벽돌 배치로 동시에 시작
4. 공을 놓치면 탈락, 모두 탈락(또는 제한 시간 10분)하면 결과 발표
   - 🕒 **오래 버티기**: 가장 오래 생존한 사람
   - 🧱 **스테이지 클리어**: 가장 많은 스테이지를 깬 사람
5. 방장이 **동일 조건**을 켜두면 모두 데미지 3 · 기본 구슬로 공정하게 대결합니다. 끄면 각자의 강화/구슬을 그대로 사용합니다.

대결 중 골드·최고기록은 변하지 않고, 끝나면 원래 기록으로 복구됩니다.

## 3. 인터넷으로 멀리 있는 친구와 하려면
서버가 인터넷에서 접근 가능해야 합니다. 방법 중 하나:
- **임시 터널**: 서버를 켠 뒤 `cloudflared tunnel --url http://localhost:3000` 또는 `ngrok http 3000` → 나온 `https://…` 주소를 친구에게 공유 (웹소켓은 자동으로 `wss://` 사용)
- **클라우드 배포**: Render, Railway, Fly.io 등에 이 폴더를 올리고 시작 명령을 `npm start` 로 지정 (`PORT` 환경변수 자동 사용)

HTML 파일을 직접(file://) 열었다면 대결 화면의 "서버 주소"에 `ws://IP:3000` 또는 `wss://도메인` 을 입력하세요.

## 4. 설정 (환경변수)
| 변수 | 기본값 | 설명 |
|---|---|---|
| PORT | 3000 | 포트 |
| MAX_PLAYERS | 4 | 방 최대 인원 |
| MIN_PLAYERS | 2 | 시작에 필요한 최소 인원 |
| MATCH_LIMIT_SEC | 600 | 대결 최대 시간(초) |
예: `PORT=8080 MATCH_LIMIT_SEC=300 npm start`

## 참고
- 생존 시간은 서버가 측정하지만, 스테이지 수는 각 브라우저가 보고하는 값입니다. 친구끼리 즐기는 용도로 만들었으며 부정행위 방지는 포함하지 않습니다.
- 코드는 `server.js`(서버), `index.html`(게임 + 대결 화면) 두 파일입니다.
